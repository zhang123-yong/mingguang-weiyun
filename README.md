# 名光智能

名光智能的欢迎封面。版式参考常见智能家居 App 的入口页：中间是品牌字标，下方是登录、注册、协议勾选，以及 QQ、微信入口。这一版先把封面定下来，字标使用「名光」。

## 这一版能做什么

- 查看名光字标和入口按钮
- 勾选协议，或在未勾选时先阅读并同意
- 打开《隐私政策》《用户协议》《第三方信息共享和SDK服务清单》

登录、注册和第三方账号会在下一步接入。同意协议后，按钮会提示即将进入对应流程。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:3847 。窄屏是整页封面，宽屏会把封面收在一块手机尺寸的白色面板里。
