# 名光智能

名光智能的家庭控制界面。封面之后可以用手机号、QQ 或微信进入，里面是首页、场景和我的。

手机号不会发送真实短信：填 11 位手机号，验证码填任意 4 到 6 位数字。QQ 和微信只确认授权，不填写对方账号密码。家庭、设备和消息保存在这台浏览器里。

## 可以做的事

- 首页按房间查看设备，开关陪伴设备和宠物，打开门锁面板远程开锁
- 右上角加号：添加设备、扫一扫、创建场景
- 首页在添加之前是空的。添加设备的分类是 AI陪伴、AI宠物、智能门锁；智能门锁里只有门锁
- 场景里的一键执行和自动化可以编辑、执行
- 我的里面有家庭、房间、成员、消息、语音服务、帮助和设置

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:3847 。窄屏是整页，宽屏会收在一块手机尺寸的白色面板里。
